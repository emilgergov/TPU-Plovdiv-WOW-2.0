# GIS карта „ИМОТИ“ — изолиран прототип

В работния контейнер са създадени `expert_module/index.html` и `expert_module/server.py`, свързани с `gis_geometry_v1.py` и локалния SQLite индекс от архива 20.10.2026. Локалният HTTP сървър слуша само на 127.0.0.1:8765.

Тест на API: `47295.27.259` → „Намерен“, една GeoJSON геометрия; `invalid` → „Невалиден кадастрален идентификатор“. UI има многоредов вход, дедупликация, избор на имот, мащабиране, преглед на архивните пресичания. Няма автоматичен избор План А/Б, нормативен извод, издаване на становище или достъп до потребителски преписки.

Това е локална демонстрация, не продукционен backend. Не се публикува в WOW 3.3; изискват се преглед на сигурността, официални граници и проверки на площи.
