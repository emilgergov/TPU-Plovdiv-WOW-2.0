# V17 — контролирана индивидуализация на Word образците

Създаден е отделен локален Python модул `paragraph_approval.py`, който изгражда манифест за преглед на всички параграфи в двата оригинални DOCX образеца. Всеки параграф трябва да бъде потвърден. Маркираните за конкретна преписка текстове се заменят само с изрично въведено съдържание; запазването им изисква мотив. Непълният преглед блокира създаването на работен DOCX.

Тестове: План А 30 параграфа — PASS; План Б 28 параграфа — PASS; непотвърдените записи блокират изхода. Резултатите са синтетични тестове, не одобрени административни предложения.

Модулът не решава нормативна приложимост, не удостоверява геометрии и не разрешава издаване или изпращане. Не е интегриран в WOW 3.3.
