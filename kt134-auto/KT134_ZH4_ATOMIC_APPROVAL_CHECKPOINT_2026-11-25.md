# КТ134-Ж.4 — атомарно експертно одобрение (тестова D1 схема)
Дата: 25.11.2026 г.
Статус: код и тестове в изолирания GitHub клон; **не е продукционно внедрено**.

## Реализирани файлове
- `KT134_TEST_ATOMIC_APPROVAL.sql`: едно условно SQLite UPDATE, което сравнява UUID преписка, proposalVersion, current registry revision, точния binding SHA-256, статус awaiting_expert и активното право за потвърждение. Двойното изпълнение не одобрява втори път.
- `kt134-test-atomic-approval.mjs`: fail-closed сървърен адаптер за **тестова ACL таблица**, който приема успех само при exactly one updated row.
- `test_atomic_approval_sqlite.py`: 10 независими тестови сценария в истинска SQLite база: точен документ, повторно потвърждение, грешен hash, грешна версия, отнети права, чужд експерт, стара ревизия, грешна заявена ревизия, superseded проект.
- `kt134-test-atomic-approval.test.mjs`: 5 Node теста за параметри и откази.
- `.github/workflows/kt134-auto-unit-tests.yml`: допълнен с изпълнение на SQLite тестовете в изолирания клон.

## Ограничение (задължително преди реално включване)
`kt134_test_approval_acl` е **само тестова** таблица. Реалният KT125 Worker има друг механизъм за локални сесии и права; не трябва да се подменя с имитирания тестов ACL. Реалната атомарна операция трябва да използва авторитетната KT125 ACL проверка **в същата транзакционна граница** (включително отказ при отнемане на правата), плюс текущата ревизия на KT126 и проверения DOCX от частния R2.

Този компонент самостоятелно НЕ е готов за публикуване. Не е удостоверено, че GitHub Actions вече са изпълнили успешно всички нови тестове. В локалния runtime изтеглянето от GitHub беше недостъпно по DNS, затова не заявяваме локален pass.
